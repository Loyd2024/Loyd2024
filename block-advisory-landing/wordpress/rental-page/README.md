# Block rental page (in progress)

A landing-page layout for listings that are for rent, the counterpart of the development layout
(`../block-development-page.php`). Work started 11 Nov 2026 at the owner's request.

- `docs/PROJECT.md`: the brief every contributor reads first (what is being built, the hard rules).
- `docs/DECISIONS.md`: decisions taken after the mapping round.
- `docs/DESIGN-BRIEF.md`: the brief for the design round.
- `notes/`: findings of the mapping round: 01 the development snippet (integration map), 02 the rental rules approved
  in October, 03 an audit of the 129 rent-only listings (with its JSON), 04 the site shell and what bleeds into a custom
  layout, 05 the other live snippets, 06 rental page UX research, 07 brand tokens and the anatomy of the development page.

Paths inside the notes that start with `ROOT/` refer to the working directory of the session that wrote them; the
files they cite that matter are copied here. Nothing in this folder is live on block.ke yet.
